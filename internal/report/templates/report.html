What this report does not claim

  • That a device was used where it was only installed. An install or an arrival date says Windows saw the device, not that a file was moved.
  • That a drive letter belonged to a device at the time a file was opened. MountedDevices holds the mapping as it stands now, and a letter is reused. A link made through a letter is capped at probable for that reason, and is only lifted there by a connection window independently covering the record.
  • That a device with no serial is a single device. Where no identity in a group reported a serial, two visits by two identical devices and two visits by one look the same in this evidence.
  • That the absence of a record is the absence of an event. Event logs roll, and a collection is a moment.
  • That a person ran a programme, where prefetch records that one ran. A prefetch file is written by the loader, and a scheduled task, an installer and a double-click all produce one.
  • That a programme ran as many times as this report can place. Windows keeps the last eight executions of each and overwrites the rest, so a run count of four hundred beside two timeline entries is the ordinary case and not a gap in the evidence. Both numbers are on every execution row.
